# 界面设计约定

Asspp Web 是查找应用、管理账号和下载 IPA 的工具。使用系统字体、单一蓝色强调和连续内容区，优先保证相同任务的结构、位置和反馈一致。

## 公共实现

- `SearchField`：首页搜索、搜索页和新建下载的查找入口。图标在输入框内，操作按钮在右侧；输入框与按钮同高 44px，间距 8px。
- `ActionGroup`：按钮组与相邻内容间隔统一 16px。操作统一为左对齐、8px 组内间距、按内容宽度排列的一组按钮；宽度不足时自然换行，不预先拆为多行，不两端分散或右对齐。安装包快捷操作与管理操作共享同一个容器，账号数据操作也放在同组。应用操作顺序为许可证、下载、历史版本。
- `Button` / `buttonClass`：所有操作按钮及外观像按钮的链接。44px 最小高度、8px 圆角、14px 字号。primary 用于提交和主要操作；secondary 用于次要操作；danger 用于删除，默认浅红底和红字，深色模式使用暗红底；确认删除才使用 danger-solid。页面只传布局类，不重写尺寸、颜色、焦点效果。
- `Input` / `Select`：所有可见输入与下拉控件，统一灰色底、16px 字号。国家和账号选择器只封装数据，不自定义另一套外观。焦点指示统一由全局 `:focus-visible` 描边控制。
- `Switch`：所有开关，轨道 48×28px，点击区域高 44px。
- `PageContainer`：唯一页头与顶部返回入口。主页面标题与操作共同行布局；子页面提供明确上级地址，加载及空数据时也显示返回。
- `Section` / `InfoRow`：详情和设置采用 24px 区块间距、分隔线与统一标签/值行，不叠加卡片或小瓷砖。
- `SoftwareHeader`：应用、安装包详情共用图标、名称、开发者和元数据布局。列表图标 40px，详情图标 80px。
- `ui-list` / `ui-list-row`：列表统一分隔线、12px 内容间距、上下左右各 16px 的行内边距。
- `EmptyState`：无数据时使用正文、说明和必要操作，不添加装饰面板。
- `Alert`、`Badge`、`Modal` 保留状态和浮层的语义。圆形样式仅用于头像、状态点、开关和进度条，普通操作不使用胶囊按钮。

## 验证要求

同一宽度比较首页和搜索页的输入框、按钮高度、内边距与间距。检查窄屏、桌面和深色模式，以及账号、搜索、应用详情、历史版本、下载、安装包详情、设置、添加账号、新建下载的往返路径。检查弹窗与加载状态。外观验证仅使用隔离预览数据；不触发真实账号重新认证或删除。

功能约束不随视觉重构改变：隐私模式、默认关闭的自动版本查询、手动模式无分页、版本缓存有效期以及 SAP 认证行为继续保持。

品牌 Logo 使用 `rounded-[11px]`。桌面侧栏保留原版 40×40px 尺寸、阴影和细描边；不要单独缩小图标。
